# Quick Start: Human Tasks
**Technical level:** Easy 
<br>
**Industry:** Any 
<br>
**Use Cases:** Human Task Orchestration

## Summary

This process shows a simple example on how to orchestrate human tasks. The example is based on our getting started guide for [Human Task Orchestration](https://docs.camunda.io/docs/guides/orchestrate-human-tasks/). There is also a [video](https://vimeo.com/762699004/e9a54ba396) available, walking you through the process details.

### Run the low-code tests in Hub

The Marketplace import does not include the test file. To run the low-code tests:

1. Download [`Quick Start_ Human Tasks.integration.test.json`](./Quick%20Start_%20Human%20Tasks.integration.test.json).
2. Use **Upload files** on the imported project's page to add it to that project.
3. Open the diagram's **Test tab**.
4. Run the suite.
5. Review the results in the run history.

Do not upload the CPT suite in `test/` to Hub. Run it with Maven.
